# Limited pilot rollout

Pilot one small department with named EMPLOYEE/MANAGER/DIRECTOR users. Freeze build SHA and migration set, complete go/no-go, take a backup, deploy migration job then applications, and run health/login/scoped BSC smoke. Start read-only familiarization, then plan workflow, then evaluation/reopen only after each checkpoint.

Monitor 5xx/error codes, readiness, DB connections, latency baseline deviation and workflow/audit anomalies. Support must capture correlation IDs, never passwords/tokens. If scoring remains unsigned, label all score UI as validation-only and prohibit payroll/formal decisions. Expand only after a reviewed pilot report.
